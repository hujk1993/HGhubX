# HGhubX v2.2.4

聚焦播放交互细节打磨、搜索历史批量管理和桌面全屏体验优化，并完成 Android TV 子项目与标准版发版流程解耦；覆盖 Windows、macOS、Linux、Android 与 iOS 标准版。

## 新增与优化
1. **启动页偏好设置（#180 / #185）**：可在「设置」中选择应用启动后默认进入的页面。
2. **搜索历史支持长按批量删除（#184）**：在搜索页与就地搜索面板长按历史词条即可进入多选批量删除。
3. **清屏锁屏按钮对齐与状态提示（#187）**：对齐横屏与净屏模式下的锁屏/解锁锚点，并补齐锁定状态提示。
4. **TV 子项目版本与 CI/CD 独立解耦（#189）**：标准版 `v*` 与 TV 版 `tv-v*` 拆分至各自工作流与独立版本号，后续互不阻塞发版。

## 修复
1. **桌面全屏定位与空闲隐藏（#180 / #183）**：修复桌面端全屏区域锚点偏移，播放空闲时自动隐藏悬浮控件与鼠标指针。
2. **暂停时点击中央播放图标恢复播放（#182）**：暂停态点击画面中央播放图标直接恢复播放，不再被外层手势拦截。
3. **移除横版视频上方重复控件（#177）**：去掉与底部操作栏重复的铺满与横屏悬浮按钮，减少画面遮挡。
4. **全屏切集方向与提示去重（#176 / #178 / #179 / #181）**：统一全屏上下划切集方向与信息流一致，旋转全屏切集提示固定在视频底部，并消除快速切换上下划开关或触及剧集边界时的提示重复堆叠。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb`；Android 标准版按 ABI 提供已签名 APK（`versionCode=2002004`）；iOS 提供未签名 `.ipa`（需自行签名安装）。
- 覆盖安装保留本机收藏、观看记录、线路与内容偏好；Android TV 版（`com.hghubx.tv`）即日起由独立 `tv-v*` 标签单独发布，不包含在本标准版 Release 附件中。
