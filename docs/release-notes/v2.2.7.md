# HGhubX v2.2.7

围绕搜索与排行榜、标签排序、吃瓜正文站内视频直达及播放器全屏交互稳定性打磨体验，并新增 Android 13+ Material You 动态主题图标适配；覆盖 Windows、macOS、Linux、Android 与 iOS 标准版。

## 新增与优化
1. **Android 13+ Material You 动态主题图标（#216）**：补充 `108dp × 108dp` 纯单色自适应矢量图层（`ic_launcher_monochrome.xml`）及圆角/默认自适应配置，支持 Android 13+ 启动器按壁纸动态着色，同时保持 Android 8–12 与既有彩色桌面图标外观不变。
2. **搜索热搜榜官网同步与单行紧凑布局（#221、#225）**：搜索页热搜请求改为直连干净路径 `{base}/search/`（移除防缓存查询串），与官网 CDN 边缘快照条目、名次及播放量保持同源同序；卡片布局调整为「序号 + 单行省略片名 + 右对齐播放量 + 右箭头」的官网紧凑单行样式。
3. **视频页操作区与全屏交互打磨（#217、#218、#219、#220）**：统一视频页顶部「搜短剧」与清晰度徽标高度及基线对齐；右侧评论入口改为与点赞/收藏一致的空心线条图标；点赞、收藏、关注共用 `playback-hint` 提示单槽位避免连续点击堆叠；全屏锁屏图标改为随闲置控件同步自动隐藏。

## 修复
1. **排行榜「热播榜」与官网实时热度不同步（#221、#226）**：修正匿名 JSON `/api/ranks/hot` 返回历史累计总榜导致的内容偏差，热播榜改为优先解析官网 `/ranks/hot/` 服务端渲染页面中的实时热度 TOP20（解析失败自动回退 `/api/ranks/hot`），「推荐榜」「潜力榜」与既有 `RankItem` 契约保持不变。
2. **标签页短剧默认排序与官网不一致（#223、#228）**：`api_tag_videos` 与前端 `tagVideos` 显式默认携带 `sort=latest`（仅明确指定 `"hot"` 时切热播排序），使标准版标签页与 TV 端标签筛选对齐官网 `/tag/{slug}/` 默认最新排序。
3. **吃瓜详情「点击观看」站内短剧链接跳出系统浏览器（#224、#229）**：新增主站及当前激活线路同源 `/video/{id}/` 严格识别校验；在吃瓜详情与 Feed 图文详情中点击站内视频链接时直接在应用内打开播放页，其余外链与非规范路径仍按原安全策略交由系统浏览器或剪贴板处理。
4. **横屏全屏切集时旋转舞台瞬时退回竖屏与提示坐标错位（#200、#215）**：同剧同作用域切集加载期间保留最近确认的视频宽高比例，避免 `.player-root` 丢掉 `.fs-landscape` 导致切集提示闪现竖屏底部；`ToastHost` 改由 `registerRotatedToastHost` 响应式同步挂载宿主，退全屏时立即回归竖屏底部。

## 安装与兼容提示
- Windows 提供 NSIS 安装包与便携压缩包；macOS 提供 Universal DMG；Linux 提供 amd64 `.deb`；Android 标准版按 ABI 提供已签名 APK（`versionCode=2002007`）；iOS 提供未签名 `.ipa`（需自行签名安装）。
- 覆盖安装保留本机收藏、观看记录、界面语言、线路与内容偏好；Android TV 版（`com.hghubx.tv`）独立沿用 `tv-v2.2.4` 发布。
