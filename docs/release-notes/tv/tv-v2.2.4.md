# HGhubX TV tv-v2.2.4

新增 Android TV 应用内一键检查与安装更新（含加速节点回退与 SHA-256 校验），并修复 FakeIP 代理连接与电视遥控器焦点恢复问题；适用于 Android TV / 电视盒子（`com.hghubx.tv`）。

## 新增与优化
1. **应用内一键检查、下载与安装更新（#201）**：在「设置 → 关于」新增独立更新卡片，支持启动后后台静默检查新版本并在侧边栏与「关于」项显示红点/「新版」角标；下载内置多加速节点与 GitHub 直连自动回退、实时进度条与取消下载，落盘前严格校验目标 URL 白名单、APK 文件头、字节长度与 SHA-256 摘要，校验通过后通过原生 `FileProvider` 拉起系统安装器（首次自动引导开启「允许安装未知应用」权限）。

## 修复
1. **FakeIP 代理环境下网络请求被误拒（#199）**：修复 TUN FakeIP 代理返回混合 IPv4 FakeIP 与 IPv6 ULA 假地址时被严格模式整组拒绝的问题，仅固定可放行地址且不放宽安全白名单。
2. **设置页「检查更新」文字与卡片尺寸跳动**：为更新主操作按钮设置固定最小宽度、为更新状态卡片设置最小高度并使用等宽数字（`tabular-nums`），避免点击「检查更新」或下载进度刷新时按钮伸缩和卡片高度跳动。
3. **设置页切换或弹窗关闭时遥控器焦点偶发抢回侧边栏（#201）**：优化 `restoreFocus` 焦点恢复时序，同步优先恢复目标焦点并避免在已有活跃非导航控件时被延迟 `rAF` 覆盖。

## 安装与兼容提示
- Android TV 按 ABI 分包提供 `HGhubX-TV_2.2.4_arm64.apk`、`HGhubX-TV_2.2.4_arm.apk`、`HGhubX-TV_2.2.4_x86_64.apk`（`com.hghubx.tv`，`versionCode=2002004`）。
- 沿用与既有 `com.hghubx.tv` 相同的签名证书与单调递增 `versionCode`，支持直接覆盖升级，保留本机收藏、观看记录、线路偏好与启动 PIN。
